## 🔹 Étape 1 : Mettre en place une redirection de port pour Ollama

### Option 1 : Redirection de port pour Ollama

Visual Studio n'accepte que les instances locales d'Ollama, cependant on peut faire une redirection de port pour utiliser Ollama sur un serveur distant.

Ouvrir un terminal en tant qu'administrateur, et exécuter la commande suivante :

```pwsh
netsh interface portproxy add v4tov4 listenport=11434 listenaddress=127.0.0.1 connectport=11434 connectaddress=[ip du serveur]
```

### Option 2 : OllamaRouter

*Préférer cette option si le GPU local de votre ordinateur dispose de 16 Go ou plus de VRAM*

Télécharger OllamaRouter depuis https://github.com/jetelain/OllamaRouter

Suivre les instructions de https://github.com/jetelain/OllamaRouter pour installer l'instance locale d'Ollama (la distante ayant été décrite dans [📘 Serveur AMD AI avec Ubuntu, Ollama et Open WebUI](server.fr.md))

Démarrer OllamaRouter

## 🔹 Étape 2 : Ajouter le modèle dans GitHub Copilot

1. **Ouvrir Visual Studio 2026** et ouvrir la fenêtre **GitHub Copilot**.

2. En bas de la fenêtre, cliquer sur le nom du modèle courant, et sélectionner à la fin **Gérer les modèles**.

3. Dans **Sélectionner un fournisseur**, choisir **Ollama**.

4. Valider en laissant l'adresse par défaut.

Les modèles installés sur le serveur distant seront désormais disponibles dans Visual Studio 2026.
