# 📘 Visual Studio 2026

**Note** : In current versions, functionality is erratic especially if the model hasn't been used recently (cold start) or if its performance is low. Qwen3.6-35B-A3B seems the most suitable for now (50 tokens/sec).

## 🔹 Step 1 : Set up Port Redirection for Ollama

Visual Studio only accepts local instances of Ollama, but we can set up port redirection to use Ollama on a remote server.

Open a terminal as administrator, and run the following command :

```pwsh
netsh interface portproxy add v4tov4 listenport=11434 listenaddress=127.0.0.1 connectport=11434 connectaddress=[server IP]
```

## 🔹 Step 2 : Add the Model to GitHub Copilot

1. **Open Visual Studio 2026** and open the **GitHub Copilot** window.

2. At the bottom of the window, click on the current model name, and select **Manage models** at the end.

3. In **Select a provider**, choose **Ollama**.

4. Validate by leaving the default address.

The models installed on the remote server will now be available in Visual Studio 2026.
